今天想让 LLM 帮你做什么？

先粘贴需求和上下文，让页面生成一份“需求评审稿”。你看这份 HTML 是否合理，确认后再复制给 LLM 执行。

推荐流程

需求 / 上下文 → 生成评审稿 → 人类 review → 复制 HTML 或 markdown → LLM 执行。Plan 是主线，demo 和风险只是帮助 review。
